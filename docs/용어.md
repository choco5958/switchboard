# Switchboard 용어

화면 글(`src/shared/i18n/*.ts`)과 README가 같은 대상을 같은 말로 부르도록 정한 목록입니다. 새 문구를 쓰거나 고칠 때 이 표를 먼저 봅니다. 표에 없는 대상을 새로 부르게 되면 여기에 한 줄 더합니다.

## 대상

| 용어 | 뜻 | English | 日本語 | 简体中文 |
|---|---|---|---|---|
| 결정 질문 | 세션이 `ask_decision`으로 올려 사람의 답을 기다리는 질문 | decision question | 判断の質問 | 决定问题 |
| 결정 대기 | 답하지 않은 결정 질문이 모이는 곳(왼쪽 아이콘 줄, 상단 칸). 상태나 큐 이름으로만 씁니다 | Decisions | 判断待ち | 待决定 |
| 결정 기록 | 답한 결정 질문의 목록 | Decision history | 判断の記録 | 决定记录 |
| 작업 | 세션이 `set_task`로 올린 일 하나 | task | タスク | 任务 |
| 단계 | 작업이 지나는 네 단계: 요구, 설계, 구현, 완료 | stage: Requirements, Design, Work, Done | 要件、設計、作業、完了 | 需求、设计、开发、完成 |
| 노드 | 작업을 나눈 진행 그래프의 한 칸 | node | ノード | 节点 |
| 세션 | 실행 중인 에이전트 대화 하나 | session | セッション | 会话 |
| 에이전트 | Claude Code, Codex 같은 코딩 CLI의 종류 | agent | エージェント | 代理 |
| 서브에이전트 | 작업 안에서 노드를 맡아 일하는 하위 에이전트. "작업자"는 쓰지 않습니다 | subagent | サブエージェント | 子代理 |
| 프로젝트 | 사이드바에 등록한 디스크 폴더 하나 | project | プロジェクト | 项目 |
| 폴더 | 디스크의 폴더. 사이드바 묶음에는 쓰지 않습니다 | folder | フォルダー | 文件夹 |
| 그룹 | 사이드바에서 프로젝트를 묶는 단위(`+ 그룹`, `그룹 삭제`) | group | グループ | 分组 |
| 도크 | 화면 아래 터미널과 작업 로그가 있는 칸. "독"은 쓰지 않습니다 | dock | ドック | 停靠栏 |
| 왼쪽 아이콘 줄 | 화면 맨 왼쪽의 아이콘 메뉴. "레일"은 화면 글에 쓰지 않습니다 | left icon bar | 左のアイコン列 | 左侧图标栏 |
| 화면 보며 고치기 | 내장 브라우저에서 요소에 코멘트를 남겨 세션에 보내는 기능 | Fix what you see | 画面を見ながら直す | 边看边改 |
| 백그라운드 서버 | 앱과 세션이 함께 쓰는 로컬 서버(코드와 README 기술 절의 "브리지") | background server | バックグラウンドサーバー | 后台服务 |
| 연결 서버(MCP) | Claude Code 밖의 CLI를 Switchboard에 잇는 서버. 설정 화면에서만 MCP라고 적습니다 | connection server (MCP) | 接続サーバー (MCP) | 连接服务器 (MCP) |
| mod | Claude Code를 Switchboard에 잇는 Claude Code 확장 기능. 처음 한 번 "mod(Claude Code 확장 기능)"로 풀어 씁니다 | mod | mod | mod |
| 계정 전환 도구(ccr) | 계정 칸을 바꿔 가며 Claude를 여는 도구. 처음 한 번 풀어 쓰고, 명령(`ccr login`)은 그대로 둡니다 | account switcher (ccr) | アカウント切り替えツール (ccr) | 账号切换工具 (ccr) |
| 저장소 | git 저장소. "레포"는 쓰지 않습니다 | repository | リポジトリ | 仓库 |
| 병합 | git merge. "머지"는 쓰지 않습니다 | merge | マージ | 合并 |
| 워크트리 | 노드마다 따로 만드는 git 작업 폴더. 실제 이름이라 그대로 두고, 작업 화면에서 한 번 풀어 씁니다 | worktree | ワークツリー | 工作树 |
| 권한 확인 | Claude Code가 도구 실행 전에 묻는 허용 요청 | permission ask | 権限の確認 | 权限确认 |
| 허용, 거부 | 권한 확인의 두 답. "거절"은 쓰지 않습니다 | Allow, Deny | 許可、拒否 | 允许、拒绝 |
| 터미널에서 답하기 | 권한 확인을 터미널의 원래 확인 창으로 넘기는 답 | Answer in the terminal | ターミナルで答える | 在终端中回答 |
| Switchboard | 앱 이름. 화면 글에서 "IDE"로 부르지 않습니다 | Switchboard | Switchboard | Switchboard |
| 초기화 | 사용량 한도가 다시 차는 일. "리셋"은 쓰지 않습니다 | reset | リセット | 重置 |

"턴"은 세션에게 보내는 프롬프트(`peer.*`)에만 씁니다. 사람이 읽는 화면 글에서는 "세션의 응답"으로 풀어 씁니다.

## 상태 라벨

상태 라벨은 명사형으로 맞춥니다.

| 라벨 | 쓰는 곳 | English | 日本語 | 简体中文 |
|---|---|---|---|---|
| 진행 중 | 작업, 노드, 서브에이전트, 예약 실행 | In progress (서브에이전트는 Running) | 進行中 | 进行中 |
| 대기 중 | 작업, 노드, 서브에이전트, 전달 | Waiting | 待機中 | 等待中 |
| 완료 | 단계, 작업, 노드, 서브에이전트, 예약 실행 | Done | 完了 | 完成, 已完成 |
| 실패 | 노드, 서브에이전트, 예약 실행 | Failed | 失敗 | 失败 |
| 시작 전 | 서브에이전트 | Pending | 開始前 | 未开始 |
| 쉬는 중 | 서브에이전트 | Idle | 休止中 | 空闲 |
| 일시정지, 정지, 꺼짐 | 서브에이전트 | Paused, Stopped, Killed | 一時停止、停止済み、強制終了 | 已暂停、已停止、已终止 |
| 멈춤 | 5분 넘게 움직임이 없는 작업, 실시간 갱신을 멈춘 화면 | Stalled, Paused | 停止 | 停滞 |
| 확인 필요 | 사이드바에서 사람의 손이 필요한 작업 묶음 | Waiting for you | あなた待ち | 等你处理 |
| 종료 | 터미널이나 개발 서버 프로세스가 끝남 | ended | 終了 | 已结束 |

짧게 써야 하는 곳은 예외로 둡니다. 휴대폰 화면의 탭은 네 칸이 한 줄에 들어가야 해서 `결정`, `권한`, `작업`, `세션`으로 둡니다.

## 저장값과 화면 라벨

DB와 도구(MCP, mod)가 주고받는 값은 한국어 그대로 둡니다. 화면은 `src/shared/i18n/index.ts`의 라벨 함수로 바꿔 보여 주고, 마크업과 CSS는 영어 슬러그를 씁니다.

| 저장값 | 한국어 라벨 | 슬러그(`data-status`, `data-kind`) |
|---|---|---|
| 단계 `작업` | 구현 | |
| 작업 상태 `하는 중`, `대기`, `보관` | 진행 중, 대기 중, 보관 | |
| 노드 상태 `대기`, `지금`, `끝`, `실패` | 대기 중, 진행 중, 완료, 실패 | `waiting`, `now`, `done`, `failed` |
| 노드 담당 `작업자` | 서브에이전트 | |
| 로그 종류 `결정 대기`, `끝`, `작업자` | 결정 질문, 완료, 서브에이전트 | `question`, `done`, `worker` |
| 코멘트 상태 `열림`, `보냄`, `해결` | 열림, 보냄, 해결 | `open`, `sent`, `resolved` |

새 저장값을 더하면 `index.ts`의 키 표와 네 언어 사전에 라벨을 함께 더합니다. `i18n.test.ts`가 브리지, mod, 앱 소스에서 저장값을 읽어 라벨이 빠진 값을 찾습니다.

## 문체

- 화면 글은 합니다체로 씁니다.
- 지시는 "~하세요"로 씁니다. "~해 주세요"는 설치처럼 사람이 시간이나 비용을 들여야 하는 부탁에만 씁니다.
- 이(가), 을(를), (으)로 같은 조사 자리표시자는 쓰지 않습니다. 값을 콜론 뒤로 보내거나("추가했습니다: {name}") 조사가 바뀌지 않는 말("에게", "에서")을 붙입니다.
- 한 문자열은 120자 안에서 한 가지를 말합니다. 더 설명할 내용은 같은 키 이름 끝에 `More`를 붙인 키("자세히")에 둡니다.
- 줄표(em dash, en dash)와 가운데점은 쓰지 않습니다. `i18n.test.ts`가 검사합니다.
